# Videre 🕸️
Una interfaz web creada para visualizar peticiones del modelo TCP/IP.

El objetivo es crear una web dinamica con un mapa 2D que muestre la procedencia de la petición para poder ver visualmente desde donde nos están llegado peticiones.

Una de las funcionalidades que distiguen este servicio es la posibilidad de detectar NICs, añadirlas dinamicamente y filtrar por estas.
